# Decision Log — UX Retruco

## Discovery session — 2026-06-06

| # | Decisión | Detalle |
|---|----------|---------|
| D-UX-01 | Modo visual | Light + Dark mode. El usuario no tiene preferencia de modo por defecto; se respeta la preferencia del sistema. |
| D-UX-02 | Tono visual base | Deportivo clásico: azul/blanco/verde. Tipografía fuerte, tablas claras, fácil lectura. |
| D-UX-03 | Identidad cultural | Sutilezas de Truco y Uruguay integradas en la paleta: celeste uruguayo (#75AADB), dorado Sol (#F5C518), verde tapete como acento oscuro. No ilustraciones/iconografía literal de naipes en MVP. |
| D-UX-04 | References externas | Ninguna referencia visual específica de otras apps. Decisión libre dentro del tono deportivo clásico. |
| D-UX-05 | Form factor primario | Mobile-first (375px+). La mayoría accede desde celular durante/después de jornadas. Admin también opera desde celular. |
| D-UX-06 | Fuentes del diseño | Brief (brief.md) + PRD (prd.md) como fuentes canónicas. PRD es la fuente de verdad para entidades, reglas y flows. |
| D-UX-07 | Handoff elegido | Google Stitch. Prompt generado 2026-06-06. Outputs guardados en imports/. EXPERIENCE.md a completar en Update mode post-Stitch. |
| D-UX-08 | Pantallas clave solicitadas a Stitch | Home/Series, Tabla de serie, Detalle de jornada, Tabla global, Login admin, Panel admin, Carga de partido. |
| D-UX-09 | Dark mode descartado | Decisión post-Stitch: solo light mode. Se eliminan todos los tokens de dark y referencias de modo oscuro de los spines. |
| D-UX-10 | Stitch output importado | Archivos en imports/: retruco_league_system/DESIGN.md + HTMLs + PNGs por pantalla. Spines distilados 2026-06-06. |
